Mini Student Hub - Lab 03

This is my Lab 03 project for Mobile Application Development.

What I Learned

1. How to make bottom tabs and stack navigation using Expo Router.

2. How to use ScrollView and Pressable components.

3. How to add local images and icons to the app.

4. How to make a live updating clock using useEffect.

How to Run

1. Run npm install

2. Run npx expo start
